The current program forces the player to manually enter the code for which Pokémon they wish to use in the game, and then
when they actually run the project, it asks them what the typings are of the 3 Pokémon they are facing. If I came back to edit
this project again, I would first add an option that allows the user to choose if they want to use the Pokémon in the lines of 
code already stored, or if they want to type in the name and type themselves each time they run the program. The second thing
I would add is a question, asking the player how many Pokémon they have and how many their opponent has. This will allow 
the code to be usable not just for the 1v1 format, but for all types of metagames. For example, in VGC, a person typically has 6 
pokemon, but can only bring 4 to the actual fight. Theoretically, by using a modified version of this code, you can determine
which 4 to bring by plugging in your 6 and your opponent's 6. Lastly, I would add an option for the player to rate each Pokémon
based on how offensive or defensive they are from 1 to 3 (1 being defensive, 2 being balanced, 3 being offensive). By doing this,
I can make certain offensive or defensive matchups more valuable in relation to their matchup.
